Durable orchestration

The scheduler knows the lifecycle, not the prompt.

The framework owns identity, retry classification, release integrity and recovery. Applications own generation, domain rules and editorial policy.

Temporal fits as an execution adapter.

Workflow ID becomes the stable executionId; Workflow History is the lifecycle authority; side effects run in idempotent Activities. Git release reconciliation remains the final cross-system correctness boundary.

Private by default

↳

Private stays private. Prompts, drafts, credentials and hidden research never enter public source, artifacts, URLs or logs.

⊙

Writes carry the last revision. Conflicts are shown to the user or scheduler instead of being overwritten.

◈
